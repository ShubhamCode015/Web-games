How to Play

Win: make three in a row — across, down, or diagonal.

Keys: D-pad or 2/4/6/8 moves the cursor, 5 or Enter places a mark, 0 opens the menu.

2 Phones: connect both phones to the same Wi-Fi hotspot, or pair them with Bluetooth tethering. Use Copy/Share/Paste or type the chunked code. On KaiOS, if copy fails, use Share/SMS or type the code.

Difficulty: Easy is random, Normal wins and blocks, Hard is unbeatable.
