How to Play

Start: a token leaves the base only on a 6. Roll a 6, capture a token, or bring a token home to get another roll.

Track: move clockwise 51 squares, then up your own home lane. You need the exact number to finish.

Capture: landing on an opponent sends it back to base, except on start squares and star safe squares.

Win: first player to bring all 4 tokens home wins. Three 6s in a row loses that turn.

Keys: 5 or Enter rolls, 1-4 picks a token, D-pad moves focus, 0 opens the menu. Tap tokens on the board too.

2 Phones: use the same Wi-Fi hotspot or Bluetooth tethering. Use Copy/Share/Paste or type the chunked code. On KaiOS, if copy fails, use Share/SMS or type the code.
